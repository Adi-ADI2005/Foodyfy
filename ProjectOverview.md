# Project Overview — Foodyfy

Foodyfy is a production-ready MERN Stack Food Delivery Application designed to provide a seamless food ordering experience.

## Purpose
The application allows users to:
- Browse food items
- Add products to cart
- Place orders
- Manage profiles
- Make online payments

Admins can:
- Manage food items
- Control orders
- Handle users
- Upload food images
- Monitor platform activity

## Frontend Architecture
The frontend is built with React and Vite for fast rendering and modern UI performance.

Main folders:
- components/
- pages/
- redux/
- services/

## Backend Architecture
The backend uses Node.js and Express with MongoDB.

Main modules:
- Controllers
- Routes
- Models
- Middlewares
- Socket Server

## Core Technologies
- React.js
- Express.js
- MongoDB Atlas
- Redux Toolkit
- Socket.io
- Cloudinary

## Application Flow
1. User registers/logs in
2. User browses foods
3. User adds items to cart
4. User places order
5. Admin manages orders
6. Real-time updates are delivered

## Scalability
The project structure is modular and scalable for:
- Multi-vendor support
- Payment gateways
- Notifications
- AI integrations
